### Why the difficulty is Beginner

The admin form and backend accept only four difficulty values: `beginner`, `intermediate`, `advanced`, and `expert`. “Beginner to Intermediate” is not a supported value. Beginner is the accurate classification because the course assumes no prior programming experience. Later modules progressively introduce intermediate application-engineering concepts; that progression belongs in the course description and outcomes, not in the difficulty field.

## Short description

Learn to design, develop, test and publish professional web applications using modern web technologies and ibrant Studio. Build practical projects from your first webpage to a complete application.

## Full course description

This practical course introduces learners to modern web development and application engineering. Starting with no prior programming experience, students learn how the web works, how to structure and style responsive interfaces, and how to build interactive applications with JavaScript.

Students use ibrant Studio as a guided development environment while learning the underlying concepts rather than treating generated output as a black box. They practise breaking down requirements, writing clear build instructions, inspecting generated code, debugging errors, testing user flows, and improving application quality.

The course then introduces component-based frontend development, HTTP and REST APIs, JSON, backend concepts, relational database fundamentals, and basic authentication and security principles. Learners complete progressively more substantial projects and finish with a deployed capstone application that addresses a defined real-world problem.

By the end of the course, each learner will have a portfolio of practical work, a published application, and project documentation explaining its purpose, features, implementation, and limitations.

## Audience and prerequisites

- Intended audience: new developers, students, career explorers, and people who want to build practical web applications.
- Prerequisites: none.
- Required access: an ibrant Academy learner account and access to ibrant Studio.
- Recommended study commitment: approximately 10 hours per week for 12 weeks.

## Learning outcomes

On successful completion, learners will be able to:

1. Explain the roles of browsers, clients, servers, HTTP, and web applications.
2. Translate a simple problem into user requirements and acceptance criteria.
3. Plan a small application and write clear, testable instructions for ibrant Studio.
4. Create semantic HTML pages and responsive layouts with CSS.
5. Use JavaScript fundamentals to implement application behaviour.
6. Build reusable interface components and manage basic application state.
7. Explain how APIs, backend services, and relational databases work together.
8. Perform basic create, read, update, and delete (CRUD) operations in an application.
9. Apply introductory authentication, validation, security, and accessibility practices.
10. Test, debug, document, and deploy a web application.
11. Present a working project with a public URL and a clear explanation of its design.

## Delivery model

- Duration: 12 weeks; estimated learner effort: 120 hours.
- Format: online, instructor-guided, project-based.
- Learning cycle: Learn → Demonstrate → Practise → Build → Test → Reflect → Publish.
- Primary environment: ibrant Studio, supported by browser developer tools and Git/GitHub.
- Every lesson should include: measurable objectives, a clear explanation, instructor demonstration or equivalent walkthrough, a guided activity, an independent exercise, knowledge-check questions, and completion criteria.
- Every module should conclude with a practical deliverable and a short assessment.

## Curriculum

### Module 1 — Introduction to Web Development and ibrant (Week 1)
1. What Is Web Development?
2. How Websites and Web Applications Work
3. Introduction to ibrant Studio and AI-Assisted Project Building
4. Understanding Project Requirements and Planning

**Module deliverable:** a personal landing page with a clear purpose, structured sections, and working navigation.

### Module 2 — HTML and Web Structure (Weeks 2–3)
1. Introduction to HTML and Document Structure
2. HTML Elements, Headings, Paragraphs, and Links
3. Images, Lists, Tables, and Multimedia
4. Forms, Inputs, and Semantic HTML

**Module deliverable:** a multi-page student portfolio website.

### Module 3 — CSS and Responsive Web Design (Week 4)
1. CSS Fundamentals and Selectors
2. Colors, Typography, Spacing, and Layout
3. Flexbox and CSS Grid
4. Responsive Design and Mobile-First Development

**Module deliverable:** a responsive business landing page.

### Module 4 — JavaScript and Interactive Applications (Weeks 5–6)
1. JavaScript Fundamentals and Variables
2. Data Types, Conditions, and Loops
3. Functions, Arrays, and Objects
4. DOM Manipulation and Event Handling

**Module deliverable:** an interactive task-management application.

### Module 5 — Modern Frontend Application Development (Week 7)
1. Introduction to React and Component-Based Development
2. Props, State, and User Interactions
3. Forms, Validation, and Application Navigation
4. Reusable Components and Frontend Architecture

**Module deliverable:** a multi-page student dashboard.

### Module 6 — Backend, APIs, and Databases (Weeks 8–9)
1. Introduction to Backend Development
2. HTTP, REST APIs, and JSON
3. Database Fundamentals and PostgreSQL
4. CRUD Operations and Connecting a Frontend to a Backend

**Module deliverable:** an inventory-management application with persistent data.

### Module 7 — Application Engineering and Deployment (Weeks 10–11)
1. Authentication and User-Management Fundamentals
2. Application Testing and Debugging
3. Web Security, Accessibility, and Performance Fundamentals
4. Deployment, Hosting, Domains, and Production Readiness

**Module deliverable:** a tested application prepared for publication, with a deployment checklist.

### Module 8 — Professional Capstone Project (Week 12)
1. Selecting and Validating a Real-World Problem
2. Requirements, Architecture, and UI Planning
3. Building, Integrating, and Testing the Application
4. Documentation, Demonstration, and Final Publication

**Final deliverable:** a complete, deployed web application that solves a clearly described problem.

## Project portfolio

1. Personal Portfolio Website — semantic structure and navigation.
2. Business Landing Page — responsive layout and visual hierarchy.
3. Task Management Application — JavaScript interactions and state.
4. Student Dashboard — reusable components, navigation, and forms.
5. Inventory Management System — API and persistent database integration.
6. Capstone Application — end-to-end planning, implementation, testing, deployment, and documentation.

Projects should be assessed against published acceptance criteria. Students must submit a working preview or public URL where applicable, a short explanation, and evidence that the required user flows were tested.
